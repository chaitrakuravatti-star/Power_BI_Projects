<h1>Super Store Sales Dashboard</h1>

Project Overview

The Super Store Sales Dashboard is an interactive Power BI report built to analyze retail sales performance across regions, states, segments, categories, sub-categories, shipping modes, and payment methods.
The dashboard provides a consolidated view of sales, profit, quantity, and delivery performance over time, enabling stakeholders to track trends, identify growth opportunities, and improve operational efficiency.

This project demonstrates practical Power BI skills including data modeling, DAX calculations, time-series analysis, and interactive visual design.

___________________________________________________________________________

**Business Objectives**

    •	Monitor overall sales, profit, and quantity performance
    •	Analyze sales trends across months and years
    •	Compare performance across regions and states
    •	Understand customer behavior by segment and payment mode
    •	Evaluate operational efficiency using shipping mode and delivery days
    •	Identify top-performing categories and sub-categories
