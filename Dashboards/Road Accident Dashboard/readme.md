**Project Overview**

This Power BI project provides an in-depth Road Accident Analysis to understand accident trends, casualty severity, vehicle involvement, road conditions, and environmental factors.
The dashboard enables stakeholders to identify high-risk areas and patterns to support road safety planning and policy decisions.

**Business Objective**

The objectives of this dashboard are to:

1.	Analyze total road accidents and casualties for the current year

2.	Compare current year (CY) and previous year (PY) casualty trends

3.	Evaluate accident severity (Fatal, Serious, Slight)

4.	Identify high-risk vehicle and road types

5.	Analyze accidents based on location, lighting, and area type (Urban/Rural)

6.	Support data-driven road safety improvements

**Tools & Technologies Used**

1.	Power BI Desktop

2.	Power Query – Data cleaning and transformation

3.	DAX – KPI calculations, YOY comparison, and measures

4.	CSV File – Input data source

   
**Dashboard Features**

1.	Dynamic slicers for Road Surface and Weather Conditions

2.	KPI cards with year-over-year percentage change

3.	Interactive trend analysis (CY vs PY)

4.	Geographic accident distribution using map visual

5.	Cross-filtering across all visuals

6.	Clean, insight-focused layout


**Visualizations Used**

1.	KPI Cards: Casualties and accidents with YOY comparison

2.	Line Chart: CY vs PY casualties monthly trend

3.	Donut Chart: Casualties by Urban vs Rural areas

4.	Donut Chart: Casualties by Light Condition (Day / Dark)

5.	Bar Chart: Casualties by Road Type

6.	Table / Card List: Casualties by Vehicle Type

7.	Map Visual: Casualties by accident location (UK)


**Key Insights**

1.	Casualties and accidents show a decline compared to the previous year

2.	Majority of casualties occur in urban areas

3.	Most accidents happen during daylight conditions

4.	Single carriageways record the highest number of casualties

5.	Cars account for the largest share of vehicle-related casualties

6.	Certain geographic locations show higher accident concentration
